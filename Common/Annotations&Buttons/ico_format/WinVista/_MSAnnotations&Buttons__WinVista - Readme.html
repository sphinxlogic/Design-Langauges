Visual Studio Image Library: Annotations & Buttons (WinVista)

Icon art
This filetype may contain more than one image size and/or color depth. They are typically used in controls which offer variations viewing style; a listbox which allows the user to choose between "small icon view" and "large icon view" is an example. The appropriate image size is displayed by the control. Note that these images are best viewed through the filesystem; the appearance in the table below is useful in identifying the image but only shows one of the representations.

Use Restrictions
As part of a visual language, the following images (or any part of the images) must be used in a manner consistent with the description indicated below:

Image Filename Usage
error.ico Generic error
Gear.ico Generic image denoting something that requires server side processing
info.ico Denoted information
Likely_unavail.ico Something is unavailable
New.ico Associated with something New, or just created
preferences.ico preferences
share_overlay.ico Use as an overlay to denote that the object marked is shared for use
Shortcut.ico Use as an overlay to denote that the object is a shortcut (link) to the source document or file.
UAC_shield.ico User Account Control.  See MSDN articles for usage requirements.
warning.ico Generic warning icon
